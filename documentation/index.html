My-Translator-App

A professional, AI-powered language translation interface.

Vite Vanilla JS Sass (BEM) MyMemory API

1. Introduction

This project is a high-performance translation tool that utilizes the MyMemory API. It features a responsive UI built with a mobile-first approach, modern Sass architecture, and efficient event handling for real-time translations.

2. Installation

To set up the development environment, follow these steps:

# Navigate to the source folder
cd my-translator-app

# Install dependencies
npm install

# Start development server
npm run dev

3. How It Works (Logic)

The core logic resides in main.js. The app listens for input events on the source textarea and triggers the translateLanguage() function.

  • Language Mapping: The convertToLanguageCode() function maps common language names (e.g., "Spanish", "Español") to ISO codes (es) required by the API.
  • API Integration: Uses the fetch API to send encoded queries to MyMemory.
  • Validation: The app checks if both language fields are filled before attempting a translation.
Pro Tip: Users can also press Enter in the language input fields to manually trigger a translation.

4. Customization

Styling (Sass)

The design is fully modular. To change the theme, edit src/_variables.scss:

$primary-color: #646cff; 
$background: #f8f9fa;
$text-color: #2c3e50;

The layout uses the BEM (Block Element Modifier) convention (e.g., .container__field), making it easy to style without affecting global scope.

Adding Languages

To support more dialects, simply extend the languageMap object in main.js with the new language name and its corresponding 2-letter ISO code.

5. Deployment

To generate a production-ready build:

npm run build

The output will be located in the dist/ directory, ready to be deployed to Vercel or GitHub Pages.
