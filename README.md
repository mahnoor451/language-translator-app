# 🌍 AI Language Translator App

A high-performance, responsive language translation tool built with **Vanilla JavaScript**, **Sass (BEM)**, and **Vite**. 

This project was developed as part of a professional portfolio to demonstrate clean codebase architecture and a modern CI/CD pipeline.

## 🚀 Features
* **Real-time Translation:** Powered by the MyMemory API.
* **Smart Language Mapping:** Supports multiple variations of language names (e.g., "Spanish", "Español", "es").
* **Mobile-First Design:** Fully responsive layout using modern CSS logic.
* **BEM Methodology:** Organized Sass structure for scalable styling.

## 🛠️ Tech Stack
* **Editor:** Cursor (AI-First Development)
* **Build Tool:** Vite
* **Styling:** Sass (SCSS)
* **Deployment:** Vercel (CI/CD Pipeline)
